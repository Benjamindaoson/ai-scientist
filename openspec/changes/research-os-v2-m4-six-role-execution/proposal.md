# M4 Six Role Agents and Execution Layer

## Why

Research OS needs enforceable occupational boundaries and subscription-first execution rather than prompt-only personas.

## What Changes

- Add strict task, result, review, action, and claim contracts.
- Add six programmatically permissioned roles and bounded work packages.
- Add Codex, human-assisted, disabled paid-API, and deterministic mock executors.
- Add a priority-ordered, audited Action Broker with isolated browser artifacts.
- Add a frozen architecture ablation and a mini E2E regression using the existing discovery benchmark.

## Scope

M4 only. Manuscript lifecycle and legacy retirement remain M5.
